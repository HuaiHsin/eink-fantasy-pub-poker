🎲 Fantasy Pub Poker: E-ink Edition
奇幻酒吧撲克：墨水屏自適應版
"A poker roguelike born in the shifting ink." > 「一場發生在墨色流轉間的奇幻牌局。」

📖 Introduction | 簡介
Fantasy Pub Poker is a poker-based roguelike game (Balatro-style) specifically optimized for E-ink devices. Set in a mysterious fantasy tavern, players challenge various races like Orcs, Elves, and Goblins using strategic card combinations and magical artifacts.

奇幻酒吧撲克是一款專為**電子閱讀器（E-ink）**開發的撲克類 Roguelike 遊戲。背景設定在一家充滿神祕色彩的奇幻小酒館，玩家將利用牌組組合與神奇遺物，挑戰獸人、精靈、地精等異種族對手。

✨ Features | 專案特色
E-ink Optimized (Zero Flickering): UI logic designed to minimize full-screen refreshes and ghosting.

墨水屏極致優化：針對電子紙物理特性設計，大幅減少全螢幕閃爍與殘影。

Unicode/ASCII Aesthetic: Minimalist visual style using custom character art, ensuring compatibility across all reading devices.

純字符美學：使用原創 Unicode/ASCII 字符畫，確保在各類高低階閱讀器上皆能完美顯示。

One-Handed Operation: Large, high-contrast buttons positioned for comfortable one-handed play.

單手友善操作：高對比大按鈕佈局，符合電子閱讀器的持握習慣。

Low Power Consumption: Pure HTML5/Vanilla JS implementation with zero heavy assets.

超低功耗：純原生 JavaScript 開發，不含任何沉重資源，極致省電。
